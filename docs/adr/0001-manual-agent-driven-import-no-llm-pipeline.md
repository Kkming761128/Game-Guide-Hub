# 匯入攻略由 coding agent 於對話中人工觸發完成，不建置自動化 LLM API pipeline

本站的攻略內容來自簡體中文／日文的來源網站，需要翻譯、拆解成單一關卡、標註寶物與關卡關聯後才能上架。我們決定不建一套自動化爬蟲＋付費 LLM／翻譯 API 的 pipeline，而是由使用者在 Claude Code 或 Codex 的對話中貼來源網址，由 agent 當場讀取、翻譯、拆解並寫入內容檔案（流程見 `AGENTS.md`）。本站是個人規模、更新頻率低的站點，排程自動化帶來的額外費用與爬蟲維運成本（處理來源站改版、反爬機制、API 用量），遠超過它省下的人力——coding agent 本身就有能力完成翻譯與結構化判讀，不需要重複建一套功能相近的外部服務。

## Considered Options

- 建一套排程爬蟲，定期抓取來源站更新，呼叫付費 LLM／翻譯 API 自動產生內容檔案。

## Consequences

新增攻略的速度受限於使用者主動發起對話匯入的頻率，沒有辦法自動偵測來源站更新並排程匯入；內容品質依賴 agent 當次判斷，錯誤靠使用者事後發現並要求修正，不是逐篇強制校對。
