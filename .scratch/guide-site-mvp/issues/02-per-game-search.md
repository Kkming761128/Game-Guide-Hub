# 02: 單遊戲內搜尋

**What to build:** 在某款遊戲的關卡列表頁上,讀者可以打關鍵字即時篩出符合的關卡——支援關卡編號、關卡名稱、寶物名稱三種搜尋對象,結果只限於目前這款遊戲,不會混進其他遊戲的資料。

**Blocked by:** 01

**Status:** ready-for-agent

- [ ] Build 階段為每款遊戲產生一份搜尋索引(JSON 靜態檔),內容包含該遊戲所有關卡的編號、名稱、寶物名稱清單
- [ ] 搜尋比對邏輯抽成一個獨立的純函式(輸入索引資料 + 查詢字串,輸出符合的關卡清單),並附上單元測試(此為全案唯一的自動化測試,需要先建立測試執行環境)
- [ ] 遊戲頁的搜尋框呼叫這個函式,即時(不需按送出)篩出結果並渲染成可點擊的關卡清單,連結到對應關卡頁
- [ ] 比對不分大小寫,子字串比對即可(不需要 fuzzy/容錯搜尋)
- [ ] 在有兩款以上範例遊戲的情況下驗證:A 遊戲頁的搜尋框不會搜到 B 遊戲的關卡或寶物
