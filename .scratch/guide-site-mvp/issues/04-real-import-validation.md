# 04: 真實攻略匯入驗證

**What to build:** 證明 03 寫的 `AGENTS.md` 手冊不只是理論上可行,而是真的能拿一篇現實世界的攻略文章跑出正確結果。挑一篇簡短的真實簡體中文或日文來源攻略(建議 2~3 關的短文,不要一次挑 1~21 關的長文,降低第一次驗證的風險與工作量),完全依照手冊流程執行匯入,並用本機瀏覽器驗證整條路徑在真實內容上成立。

**Blocked by:** 02、03

**Status:** ready-for-agent

- [ ] 挑定一篇真實來源網址(簡體中文或日文),記錄在這張票或對應內容檔案的 `sourceUrl` 裡
- [ ] 完全依照 `AGENTS.md` 的步驟執行匯入(不跳過任何一步、不臨時用手冊沒寫的做法)
- [ ] 產生的每個關卡檔案都通過 01 定義的 schema 驗證、`sourceUrl` 都存在
- [ ] 若原文有跨關卡關聯或寶物條件,匯入後在對應關卡頁能看到正確的超連結與寶物標註
- [ ] 原文的強調/附註處在渲染後的頁面上有螢光筆樣式
- [ ] 在這款遊戲的頁面上用搜尋框實測:搜關卡編號、關卡名稱、寶物名稱都能找到正確的關卡
- [ ] 跑過 03 的「完成後自檢清單」,全部打勾
- [ ] 若匯入過程發現 `AGENTS.md` 的描述不夠精確或有遺漏,回頭補到 03 的文件裡(文件要能一次到位給之後的匯入用)
